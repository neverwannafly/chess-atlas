# Chess Atlas brand assets

The mark (a board square turned into a map pin, with two checkered cells) is an original
drawing made for Chess Atlas. No third-party icon or artwork is used.

The wordmark outlines in `lockup.svg` and the text in `og.png` are set in **Geist SemiBold /
Regular** by Vercel, licensed under the SIL Open Font License 1.1
(https://github.com/vercel/geist-font/blob/main/LICENSE.TXT). The OFL permits embedding
outlines of the font in logos and images.
